# 🍷 Sabor Urbano

Landing page responsive y moderna para un restaurante ficticio, desarrollada como proyecto de portfolio utilizando **Angular 18**, **Tailwind CSS** y buenas prácticas de desarrollo profesional.

[🌐 Ver demo online](https://sabor-urbano-gold.vercel.app)

---

## 🧩 Características principales

- ⚙️ **Angular 18 con Standalone Components**
- 🎨 **Tailwind CSS** para diseño responsivo y limpio
- 💬 **Opiniones de clientes animadas**
- 🍽️ **Carta de platos interactiva con modal**
- 🖱️ **Animaciones suaves al hacer scroll**
- 📬 **Formulario de contacto estético y funcional**
- 🦶 **Footer elegante con redes sociales y horario**
- 🔀 **Routing configurado para vistas separadas**
- 📱 **Diseño completamente mobile-first**

---

## 🚀 Tecnologías

- Angular 18 (con routing y standalone components)
- Tailwind CSS
- TypeScript
- HTML + CSS modernos
- IntersectionObserver para animaciones
